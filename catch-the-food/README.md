# Catch The Food

[Play Catch The Food](https://irrelative.github.io/catch-the-food/)

Catch the food shown in the target card, protect the picnic, and unlock five animal friends.

## Controls

- Move with the arrow keys or A/D.
- On touch devices, use the large left and right buttons.
- Pause with P, Escape, or the pause button.

The game is a dependency-free static site. Open `index.html` through a local web server or deploy the `catch-the-food` directory to GitHub Pages.

Production builds display a version in the header. GitHub Actions stamps it as `v1.0.<run number>`, so every deployed revision receives a higher version automatically; local development displays `v1.0.dev`.
